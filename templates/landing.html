快速开始

三步开始使用

01

创建命名空间

访问控制台，创建你的专属命名空间，获得独立的 API 端点。

https://gateway.tech/your-namespace/v1/chat/completions
02

配置模型

点击右上角 Models 按钮，添加模型配置（API Base URL 和 API Key）。

Model: gpt-4
API Base: https://api.openai.com/v1
03

开始调用

使用标准 OpenAI 格式调用，无需指定 by 参数，自动使用默认模型。

POST /your-namespace/v1/chat/completions
{ "model": "gpt-4", "messages": [...] }
