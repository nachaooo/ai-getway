三步开始使用

简单配置，即可享受智能 API 管理

1

创建命名空间

访问控制台，创建你的专属命名空间，获得独立的 API 端点。

https://token.fangna.tech/your-namespace/v1/chat/completions
2

配置模型

点击右上角 Models 按钮，添加你的模型配置（API Base URL 和 API Key）。

模型: gpt-4  |  API Base: https://api.openai.com/v1
3

开始调用

使用标准的 OpenAI 格式调用，无需指定 by 参数，自动使用默认模型。

POST /your-namespace/v1/chat/completions
{ "model": "gpt-4", "messages": [...] }
