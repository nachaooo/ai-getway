Quick Start

Three Steps to Begin

01

Create Namespace

Visit the console and create your dedicated namespace to get an independent API endpoint.

https://gateway.tech/your-namespace/v1/chat/completions
02

Configure Models

Click the Models button in the top right corner to add your model configuration (API Base URL and API Key).

Model: gpt-4
API Base: https://api.openai.com/v1
03

Start Calling

Use standard OpenAI format to make requests. No need to specify the by parameter — it automatically uses the default model.

POST /your-namespace/v1/chat/completions
{ "model": "gpt-4", "messages": [...] }
